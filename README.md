# MovieRadar

Веб-приложение для просмотра информации о сериалах и шоу: поиск по каталогу, карточка шоу, расписание эпизодов на выбранную дату, профиль с локальными списками «смотреть позже» и оценками. Данные загружаются из внешнего API [TV Maze](https://www.tvmaze.com/api) (REST). Авторизация на стороне клиента (localStorage), без сервера.

**Используется:**

- React 19;
- React Router DOM 7;
- TypeScript;
- Ant Design 6;
- Vite 8;
- ESLint 9 + typescript-eslint;
- React Compiler (Babel).

**Деплой:** GitHub Pages — [https://mindvan.github.io/movieradar/](https://mindvan.github.io/movieradar/) (`npm run deploy`: сборка и публикация каталога `dist` в ветку `gh-pages` через `gh-pages`).
